# 协议边界

> [文档索引](README.md) · [测试](testing.md)

本项目将接口形状、客户端实现和在线服务规则分开处理。文档中的路径、字段和示例用于说明客户端如何组织请求；服务端可能按账号、时间、场馆和部署版本改变行为。

- `there` 四入口共用 `/api/v3`，用 `x-room-type` 选择资源范围。
- 超星座位是另一套服务，使用独立凭据和业务端点。
- HTTP 200 仍需检查业务响应；写操作后重新查询预约状态。
- there 的 `checkInUse` 保留为实验性操作，其实际响应和适用条件尚不确定。
- 超星的首次预约、续约及当前预约操作受动态页面值和服务端规则约束。

[OpenAPI 规范](openapi/there.openapi.yaml)记录 there 接口结构；[离线测试](testing.md)检查客户端请求组装和错误处理，不代表实时服务状态。
